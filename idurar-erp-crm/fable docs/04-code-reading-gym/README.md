# 04 — Code Reading Gym

Active practice, not reading. You'll annotate real excerpts, fill trace tables, contrast bad-vs-better code, and review fake PRs — all anchored to IDURAR.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 excerpts to annotate for inputs, outputs, invariants, side effects, failure modes.
2. [02-trace-tables.md](02-trace-tables.md) — 6 trace tables across UI, persistence, auth, and error paths.
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 novice-vs-better pairs tied to real repo patterns.
4. [04-review-katas.md](04-review-katas.md) — 8 fake PRs to review, graded blocking/important/optional.

The transferable skill is **reading code like a reviewer**: not "what does this do" but "what does it assume, what does it own, what breaks it, and what would I say in a review." Do the work before reading the rubric.
